# 💰 Python Expense Tracker

A beginner-friendly **Console-Based Expense Tracker** built using Python.

This project demonstrates the fundamentals of Object-Oriented Programming (OOP), file handling, exception handling, and data management using Python's standard library.

---

## 📌 Features

### Core Features
- ➕ Add New Expense
- 📋 View All Expenses
- 📂 Category-wise Expense Tracking
- 🔍 Search Expenses
- 💵 Calculate Total Expenses
- 💾 Save Expenses to JSON File
- 📂 Load Saved Expenses Automatically

### Bonus Features
- 🗑 Delete Expense
- ✏ Edit Existing Expense
- 📅 Monthly Expense Summary
- 📈 Highest & Lowest Expense Tracker

## 💾 Data Storage

All expenses are stored locally in a JSON file.

Example:

```json
{
    "date": "22/07/2026",
    "category": "Food",
    "description": "Lunch",
    "amount": 250
}
```

This ensures that expense records persist even after the application is closed.
